# Aante (爱安特)

> Aante — Aante (Changzhou) Precision Machinery Co., Ltd. (爱安特（常州）精密机械有限公司) — is a
> Chinese factory-automation (FA) parts distributor running a one-stop industrial e-commerce
> procurement platform at ant-fa.com. It sells linear-motion, transmission, standard, machined,
> framing, motion-unit, electrical and pneumatic components across 96 product categories and
> roughly two million SKUs, distributing 30+ international brands (SMC, THK and others) alongside
> its own Aante-branded line, to customers in semiconductors, new energy, 3C electronics,
> photovoltaics, LCD, automotive, medical and food manufacturing.

## API status

**Aante publishes no public API.** As of 2026-09-05 an API Evangelist enrichment pass probed every
host this record knows and found no developer portal, no API reference, and no machine-readable
contract of any kind:

- No OpenAPI/Swagger at `/openapi.json`, `/openapi.yaml`, `/swagger.json`, `/v1/openapi.json`,
  `/api-docs`, `/docs` or `/redoc` on `ant-fa.com` or `www.ant-fa.com` (404, or HTTP 200 returning
  the site's Nuxt single-page-application HTML shell).
- No GraphQL surface (`/graphql` returns the same HTML shell).
- No MCP server, and no A2A agent card at `/.well-known/agent-card.json` or `/.well-known/agent.json` (404).
- No `/llms.txt` (404).
- No `/.well-known/` document of any kind — see `well-known/aante-well-known.yml` for the full probe log.
- No `api.`, `open.`, `openapi.`, `developer.`, `docs.` or `gateway.` subdomain exists (NXDOMAIN).
- No first-party GitHub organization, and no first-party SDK on npm, PyPI, Maven Central, NuGet,
  pkg.go.dev, RubyGems, Packagist or crates.io.

Ordering, quoting and bulk-inquiry all run through the authenticated web storefront and its
WeChat mini-program; there is no documented programmatic channel.

## Notes for agents

- The site is Chinese-language only and server-renders its catalog, product and article routes;
  unmatched routes return a 31KB HTML shell with HTTP 200, so status code alone is not a reliable
  existence signal on this host.
- `robots.txt` on ant-fa.com allows a named list of crawlers (Baiduspider, Bingbot, Googlebot,
  Sogou, 360Spider and others) and ends with `User-agent: *` / `Disallow: /`. Agents outside that
  allowlist are asked not to crawl.
